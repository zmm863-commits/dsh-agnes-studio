# 逐项拆开看：泡泡猫的影视工具 v1.0.0

**一句话结论**：15 个功能逐个跑给你看——每个都有截图，每个都有真实产物。

下面按功能走。每节的结构都一样：能干什么、界面长什么样、跑出来的东西是什么。

所有产物都由本机实际运行产生，不是示意图。

## 怎么装

命令行装（推荐）：

```bash
dsh plugin --profile web add dsh-agnes-studio
```

装本地目录：

```bash
dsh plugin --profile web add /你的路径/dsh-agnes-studio
```

装完**重启一次 DSH**，再刷新页面。面板入口在侧边栏「泡泡猫的影视工具」。

也可以在插件页的「发现」里加索引地址直接装，索引是：

```text
https://gitee.com/paopaocat/dsh-agnes-studio/raw/main/market-index.json
```

## 短剧

故事梗概、剧本、分镜、素材，每一步停下来等你确认。

![短剧页](配图/v100/05-短剧.png)

产物是文本。这是它写出来的故事开头：

```text
暴雨夜，老旧的"时间当铺"内，灯光昏黄。林远站在柜台前，
面前放着一枚怀表，表盘上的指针正在疯狂逆转。
他深吸一口气，声音沙哑："我要买回我女儿生命最后的一小时。"
```

这是它拆出来的第一镜分镜：

```json
{
  "shot_index": 1,
  "scene_desc": "暴雨中的公交站，霓虹灯在积水中晕开模糊色块，林默站在站台尽头。",
  "camera": "中景（Medium Shot）",
  "camera_movement": { "type": "缓慢推进（Slow Push In）" },
  "dialogue": ""
}
```

实测：故事 709 字、剧本 744 字、分镜 12 个、素材 8 个。

**人话**：这一页的产物是文字，不是视频；视频要你在镜头确认后再生成。

![小说工具](配图/v100/12-小说工具.png)

**人话**：拆完每集一个文件，直接能拿去改剧本。

## 多能宝箱：语音合成

五个页签共用一个两列骨架。先看文本转语音。

![多能宝箱](配图/v100/03-素材库.png)

产物是 WAV 音频。这是合成出来的真实波形：

![TTS 波形](配图/v100/22-TTS音轨.png)

实测：一句话合成 83KB WAV，耗时 1.3 秒。

## 多能宝箱：歌词对齐

按字数比例分配时间，再用停顿检测吸附边界。

产物是 SRT 字幕，实测 8.48 秒音频、4 处停顿全部吸附：

```text
1
00:00:00,000 --> 00:00:01,540
雨落下来

2
00:00:01,540 --> 00:00:03,820
落在旧巷子里
```

**人话**：每行都标了是「吸附」还是「比例」，不假装逐字精确。

## 多能宝箱：素材库

扫描本地目录，ffprobe 读时长分辨率，按文件名打标签。

产物是索引与匹配结果：

```text
索引 3 条（新增 3，跳过 0）
按「夜景」命中 1 条：城市夜景-车流.mp4
时长 2.0s · 1280×720 · 无音轨
```

**人话**：中文按 2-gram 补词元，所以「城市夜景」能被「夜景」命中。

## 视频解析

ffmpeg 找真实切点，视觉模型读每一镜的画面。

![视频解析](配图/v100/04-视频解析.png)

产物是结构化解析结果：

```text
时长 6.0s | 3 个镜头 | scene-cut

整体理解：视频由红、蓝、绿三个纯色块按顺序交替显示，无人物无情节。
首镜：画面为一片均匀纯净的纯红色，无人物、无动作、无纹理变化。
景别/运镜：特写 / 固定
提示词：纯红色色块，高饱和度，无纹理，无光线变化，静态画面，极简主义。
警告：音轨提取失败（可能无音轨），未做台词转写
```

**人话**：切点归 ffmpeg，画面归模型，台词归语音识别，拿不到就如实写警告。

## 设置：模型配置

六个厂商的密钥与端点、自定义模型、连通测试。

![模型配置](配图/v100/02-模型配置.png)

产物是这份模型清单——内置 20 个，在线抓到 12 个：

```text
可选模型：内置 20 个、自定义 0 个、厂商在线返回 12 个
文本：agnes-2.5-flash / agnes-3.0-flash / deepseek-chat …
图片：agnes-image-2.5-flash …
视频：agnes-video-2.5-flash / MiniMax-H3 …
```

新增「按用途的默认模型」：文本、视觉、图片、视频、语音各一个默认。

**人话**：选一次，所有写稿类功能一起跟着走。

## 这次改了什么

布局：15 个页面统一成「左看右填」，参数列可收起。

表单：深色面板里的白色输入框没了，文件选择器换成中文控件。

主题：取消浅色，只保留深色一套皮肤。

假功能：背景视频、MTV、公众号、小说工具、工具箱语音、视频反推，全部换成真实调用。

## 自检发现的问题

发布前逐项打真实接口，抓到五个 bug：

短剧与口播引擎各缺一个 import，运行时直接崩；口播素材不认本地路径；去 AI 味结果从未显示；短剧「确认」不推进流水线，永远卡在原地。

**人话**：这些只有真跑一遍才会暴露，看代码看不出来。

## 兼容性

DSH **0.2.2-rc.3** 实测通过。

官方包要求 `^0.1.0-rc.6 || ^0.2.0-rc.1`，Cordis 4.0.1。

客户端需要注入五项：runtime、store、ui-conversation、ui-layout、ui-tool。

本机需要 ffmpeg 与中文字体；口播另需语音服务的 Key。

宿主侧改动需重启一次 DSH。

## 已知限制

动作迁移需要的专用模型，本机所属分组没上架；公众号发布需自备 AppID 与 AppSecret；ComfyUI 需自备实例地址。

这些都不假装成功，宁可报一句明白话。
